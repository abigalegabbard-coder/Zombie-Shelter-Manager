How to play:

Run the program in the main file called "main.py"


Explaining the functions:

    pressEnter()
        It makes the user have to press enter before the next screen is displayed

    main_menu()
        Displays the main menu, with the choices that the user can pick from to play the game

    viewShelterInfo()
        Grabs the info from the shelter and displays it for the user to read

    clearScreen()
        Clears the terminal

    changeValueSelect()
        Grabs the users selection on what they want to change and makes sure it is in range

    log_file()
        Creates and updates a .log file with what time the changes were made and what was actually changed

    getnewValue()
        It makes sure that the input is of the correct data type

    changeValue()
        Actually updates the shelter.json file with the user's input

    viewLog()
        Lets the user view the changelog

    returnJSON()
        Returns the shelter.json back to its original information

    clearLog()
        Deletes the shelter.log file
